## Agent Brief

**Category:** enhancement
**Summary:** Add catalogue-backed file actions for opening, editing, locating, and copying the current photo's path.

**Current behavior:** The Photo Workspace provides an active photo and may have multiple selected photos, but the file pane has no actions for launching a photo, locating it in the file manager, or copying its absolute path. The existing action catalogue owns commands, shortcuts, help, and command completion.

**Desired behavior:**

- Provide OS-default Open, explicit Open in GIMP, Copy absolute path, and Reveal in Explorer actions in the existing catalogue.
- OS-default Open submits each selected path independently through the platform association. With multiple selected photos, either Open action prompts for All, active Only, or Cancel; Cancel is the default and Escape action.
- Open in GIMP uses `C:\Program Files\GIMP 3\bin\gimp-3.exe` on Windows. Elsewhere it locates `gimp` on `PATH`; if unavailable, it gives non-modal footer feedback. An All request invokes GIMP once with all selected paths and must reuse an existing GIMP instance when possible.
- Copy writes every selected absolute path as newline-delimited plain text; Reveal operates on the active photo only. Single-path Copy reports `"<absolute path>" was copied`; multi-path Copy reports the copied count; Reveal reports `Revealing "<absolute path>" in Explorer…` when initiated. No applicable photo and launcher failures use non-modal footer feedback.
- The file-pane context menu contains the four new actions. Right-clicking an unselected photo selects it alone; right-clicking a selected photo preserves the current selection; Ctrl+right-click adds an unselected photo, makes it active, then opens the menu.

**Key interfaces:**

- `ActionSpec`, command bindings, shortcut bindings, and key routes — register `:open`, `:opengimp` with `:gimp` alias, `:copypath`, and `:reveal`; add file-pane `Space O`, `Space G`, `Space C`, and `Space R` routes.
- The file-pane key routing and footer feedback — pressing `Space` shows the available `O`, `G`, `C`, `R`, `Y`, and `P` continuations for 1,000 ms, then clears or replaces the hint when the sequence resolves or expires.
- Main-window platform-launch and clipboard helpers — isolate OS association, GIMP invocation, Reveal, and clipboard effects for deterministic offscreen tests.
- Photo Workspace selection and active-path state — preserve the context-menu selection rules above.

**Acceptance criteria:**

- [x] The four commands appear in command listing and completion, and the four file-pane routes coexist with existing `Space Y` and `Space P` routes.
- [x] A Space press gives the six-action footer hint for 1,000 ms.
- [x] Copy writes every selected path and Reveal uses the active path, with the specified initiation/no-applicable-photo/error footer feedback.
- [x] Each Open action immediately opens the active photo for a single selection and presents an All / Only / Cancel choice for a multi-selection; Cancel and Escape do not launch anything.
- [x] Default Open delegates one path at a time to the OS association. GIMP invokes every selected path in one call, resolves its executable by the agreed platform rules, and reports unavailable/launcher errors non-modally.
- [x] The context menu and right-click selection behavior match the agreed normal and Ctrl-modified rules, including active-preview updates.
- [x] Offscreen coverage mocks all platform effects and covers active-only, All, Cancel, failures, no-applicable-photo, commands, shortcuts, context-menu behavior, and preview targeting.
- [x] Windows manual acceptance verifies that a multi-photo GIMP request opens into one already-running GIMP instance.

**Out of scope:**

- User configuration of the GIMP executable or support for named editors other than GIMP.
- IrfanView configuration, bundling, or detection.
- Bulk Reveal.
- An internal image viewer or file manager.
