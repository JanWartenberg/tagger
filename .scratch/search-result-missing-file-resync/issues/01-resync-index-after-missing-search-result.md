# 01 — Repair Index After a Missing Search Result

Status: needs-triage
Category: bug
Priority: high
Blocked by: None

## Reported Behavior

A search for `Kalanderlerche` returned four indexed results, then TAGGER reported `Error: File not found` for one result.

## Requested Behavior

- Treat a missing search-result file as a stale-result index-repair signal.
- Start a background stale-result index repair for the relevant root.
- Remove the missing path from the SQLite index.
- If the file was renamed and is found during the scan, index its current path and tags.

## Terminology

A **stale-result index repair** is a background root-index refresh triggered because TAGGER cannot read a path returned by an active indexed search. It is distinct from, and must not use, the IPTC-empty filter's future `:resync` command.
